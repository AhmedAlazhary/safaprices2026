# نظام إدارة المخزن والأصول - مكتب الصفا

نظام متكامل لإدارة المخزن والعهد والأصول مع الربط المحاسبي والالتزام بالدورة المستندية.

## 🏗️ هيكلة قاعدة البيانات (Firestore Collections)

### 1. Items (المخزن)
```javascript
{
  itemId: (Auto-generated),
  name: String,
  categoryId: String,
  unit: String,
  quantity: Number,
  unitPrice: Number,
  location: String,
  status: String, // "جديد" | "مستعمل" | "خردة"
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

### 2. Custody (العهدة والتصفيات)
```javascript
{
  custodyId: String,
  employeeName: String,
  date: Date,
  linkedCashId: String, // ID العملية من الخزينة
  totalAmount: Number,
  status: String, // "Open" | "Closed"
  items: [
    {
      itemId: String,
      quantity: Number,
      price: Number,
      accountingItem: String,
      assetId: String
    }
  ],
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

### 3. Assets (الجراج/الأصول)
```javascript
{
  assetId: String,
  type: String, // "سيارة" | "معدة"
  plateNumber: String,
  currentCounter: Number,
  driver: String,
  status: String, // "نشط" | "صيانة" | "متوقف"
  value: Number,
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

### 4. Lookups (القوائم الديناميكية)
```javascript
{
  categories: ["قطع غيار", "زيوت", "خردة"],
  accountingItems: ["مصروفات وقود", "مصروفات صيانة", ...],
  units: ["قطعة", "لتر", "كيلو"],
  locations: ["المخزن الرئيسي", "مخزن الخردة", ...],
  assetTypes: ["سيارة", "معدة"],
  assetStatuses: ["نشط", "صيانة", "متوقف"],
  itemStatuses: ["جديد", "مستعمل", "خردة"]
}
```

## 🔄 الميزات البرمجية التفاعلية

### نظام التزامن التلقائي (Auto-sync Lookups)
- عند إدخال أي "صنف" أو "بند محاسبي" جديد، يتم التحقق تلقائياً وإضافته إلى Lookups
- تظهر الأسماء كمقترحات (Auto-complete) لمنع التكرار
- تحديث ديناميكي للقوائم المنسدلة

### القواعد المحاسبية والمنطقية
- **مبدأ القيد المزدوج**: أي تصفية عهدة تنقص حساب العهدة وتزيد حساب المصاريف
- **Validation**: يمنع النظام حفظ أي عملية صرف إذا كانت الكمية غير متوفرة
- **Atomic Updates**: استخدام Firestore Transactions لضمان عدم حدوث تضارب
- **تنبيهات**: إشعارات عند وصول المخزون لحد الأمان

## 🎛️ واجهة المستخدم (UI Sections)

### 1. صفحة المخزن
- جدول تفاعلي للأصناف (قطع غيار، زيوت، خردة)
- نظام فلترة حسب النوع والحالة
- بحث متقدم
- إضافة/تعديل/حذف الأصناف
- تقرير جرد شامل

### 2. صفحة الجراج/الأصول
- سجل الأصول (السيارات والمعدات)
- ربط كل أصل بمركز تكلفة
- متابعة العدادات والصيانة
- إدارة السائقين والحالات

### 3. صفحة العهدة (التصفية)
- سحب رصيد العهدة من الخزينة
- نموذج تصفية متكامل
- إضافة الأصناف المصروفة من المخزن
- تنفيذ Transaction لخصم الكميات وتحديث الرصيد

### 4. صفحة التقارير
- تقرير جرد المخزن
- تقرير العهد المفتوحة والمصفية
- تقرير الأصول والسيارات
- تصدير البيانات

2. **تهيئة البيانات الأولية**

   - الدخول للداشبورد
   - الضغط على "فتح نظام المخزن والأصول"
